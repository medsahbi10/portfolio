# Mohamed Sahbi Ben Rejeb – Portfolio

Personal portfolio of **Mohamed Sahbi Ben Rejeb**, Data & AI Engineer (BI · AI & LLMs · SAP BTP · Full-Stack), styled like Visual Studio Code.

## Pages

- **Home** – intro and focus areas
- **About** – bio, skills, education and certifications
- **Experience** – professional experience
- **Projects** – projects, filterable by area (BI & Data, AI, SAP, Software)
- **GitHub** – live GitHub stats and contribution calendar
- **Contact** – email, GitHub and LinkedIn

It also includes an interactive terminal (`` Ctrl+` ``), a command palette (`Ctrl+Shift+P`) and several color themes.

## Tech stack

Next.js · React · TypeScript · CSS Modules

## Running locally

```bash
bun install
bun --bun next dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Editing content

- Projects: `data/projects.ts`
- Experience: `data/experience.ts`
- Bio, skills, education, certifications: `app/about/page.tsx`
- Contact links: `components/ContactCode.tsx`
